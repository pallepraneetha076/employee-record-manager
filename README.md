# Employee Record Manager

A Flask-based web application for managing employee records using Git and GitHub for version control.

## Features

- Add Employee
- Update Employee
- Delete Employee
- Search Employee

## Technologies Used

- Python Flask
- HTML
- CSS
- JavaScript
- SQLite
- Git & GitHub
